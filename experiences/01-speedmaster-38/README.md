# Experience 01 — OMEGA Speedmaster 38

Independent interactive design concept for the 2026 black-dial OMEGA Speedmaster 38.

## Interaction system
- Pointer parallax hero
- Start/stop/reset chronograph
- Keyboard Space and R controls
- Draggable / touch / keyboard tachymeter ring
- Three-view product gallery
- Scroll-driven reveal and scale effects
- Reduced-motion support
