# Experience 03 — Porsche Taycan Turbo GT / Attack Mode

Independent interactive concept for the Taycan Turbo GT with Weissach Package.

## Technology
- React 19 + Vite
- Three.js + React Three Fiber
- Procedural 3D speed-tunnel environment
- Real Porsche vehicle photography layered above the generated environment

## Interaction system
- Scroll-responsive 3D speed field
- Hold-to-engage Attack Mode
- Road / Track / Night scene modes
- Interactive simulated battery state
- Responsive telemetry and performance data
- Reduced-motion fallback that removes the WebGL layer

## Product facts
Factual copy is based on current Porsche product information: 760 kW / 1,034 PS overboost with Launch Control, 0–100 km/h in 2.2 seconds, 305 km/h top speed, 800-V architecture, up to 320 kW DC charging, and approximately 18 minutes for 10–80% under Porsche's stated optimal conditions. Attack Mode can provide an additional 120 kW under Porsche's stated conditions.

This is not an official Porsche website. Vehicle imagery is served from Porsche's official Storyblok assets.
