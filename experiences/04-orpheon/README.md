# Experience 04 — Diptyque Orphéon / After Midnight

Independent fragrance experience built with raw Three.js and a custom GLSL fragment shader.

## Interaction system
- Pointer-reactive WebGL smoke/light field
- Four scent-note scene retunes: juniper berry, cedar, tonka bean, jasmine
- Sillage intensity slider
- Jazz-pulse shader speed toggle
- Paris room-state switch
- Restrained 2–3° product-photo tilt (no fake bottle rotation)
- Reduced-motion fallback

## Product fidelity
The bottle is a real Orphéon retail photograph, not synthetic 3D. Factual copy follows Diptyque's current product description: juniper berry, cedar, tonka bean and jasmine; made in France; refill service at selected boutiques.
