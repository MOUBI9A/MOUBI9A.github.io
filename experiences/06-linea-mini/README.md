# La Marzocco Linea Mini — Experience 06

Independent interactive specialty-coffee concept built around La Marzocco's current Linea Mini.

## Experience
- Canvas 2D espresso stream renderer
- Optional Web Audio interaction cue
- Live extraction timer
- Four-step ritual selector
- Responsive mobile/tablet/desktop layout
- Reduced-motion support
- Serverless config and telemetry endpoints

## Product fidelity
The primary machine image is served from La Marzocco's official `lamarzocco.com` product assets. Product facts are limited to current manufacturer materials used in the experience.

## Backend
- `/api/config` — read-only product/config payload
- `/api/telemetry` — stateless interaction-event endpoint; does not persist user data

Independent portfolio concept; not affiliated with La Marzocco.
