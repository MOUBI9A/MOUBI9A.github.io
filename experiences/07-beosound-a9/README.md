# Bang & Olufsen Beosound A9 5th Gen — Experience 07

Independent room-scale interaction concept for the Beosound A9 5th Gen.

## Experience
- DPR-aware Canvas 2D acoustic field
- Pointer/touch listener-position interaction
- Wide / Focus / Night field modes
- Architectural editorial layout
- Responsive mobile/tablet/desktop design
- Reduced-motion support
- Stateless Vercel Function endpoints

## Product fidelity
The hero uses Bang & Olufsen's official Contentful product asset. No synthetic speaker specifications are presented.

## Backend

- `/api/telemetry` — stateless interaction events, no persistent user data
